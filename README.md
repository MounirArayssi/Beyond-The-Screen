
# Beyond the Screen Assist

A basketball analytics project investigating how on-ball
screens create offensive advantages beyond traditional
screen-assist statistics.

## Research Question

How often do screens create measurable separation and
quality scoring opportunities, regardless of whether
the resulting shot is made?

## Data

SkillCorner Open Basketball Data — 2025-26 Liga ACB.

- 25 FPS player tracking
- Labeled on-ball screen events
- Defensive coverage classifications
- Shot outcomes and shot-quality metrics

Source:
https://github.com/SkillCorner/opendata-basketball

## Methods

1. Align screen events with player tracking.
2. Calculate separation and defensive recovery.
3. Link screens to subsequent shot attempts.
4. Evaluate potential screen assists.
5. Visualize findings and limitations.
